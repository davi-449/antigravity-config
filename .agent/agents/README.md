# 🤖 Antigravity 2.0 Native Execution Architecture

## Doutrina Operacional: Single-Agent Direct

O Antigravity 2.0 opera exclusivamente como **Single-Agent Direto (Concurrency: 1)**.
A especificação, codificação cirúrgica, validação de terminal e testes são de responsabilidade direta do agente raiz do IDE.

Subagentes são acionados apenas sob demanda para pesquisas assíncronas de leitura na web ou documentação (`read-only`).
Todas as personas de debate multi-agente e conselhos foram arquivadas em `_archive_multiagent/` para eliminar context bloat e amplificação de erros.
