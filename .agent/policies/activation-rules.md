# Ativação de skills

Use a skill da fase solicitada: `sdd-proposal`, `sdd-apply`, `sdd-archive` ou `sdd-debug`. Os aliases `vibe-*` continuam válidos. Consulte [o índice](../../skills/INDEX.md) para a skill técnica do domínio realmente afetado.

Leia apenas o necessário. Para uma edição simples, a evidência no arquivo existente basta. Em decisão incerta ou sensível, o agente principal pode pedir ao `sdd-reviewer` uma revisão em leitura. Ele confere os achados antes de agir.

Bundles, `/route-task`, `/skill-audit` e o roteamento de workers v6 são históricos; não os ative por padrão. `/council` só é usado sob pedido explícito.
